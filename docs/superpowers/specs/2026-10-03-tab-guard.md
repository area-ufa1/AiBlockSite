# Спека: приложение «Страж вкладок» (Android)

## Идея в двух словах
Приложение для Android, которое помогает не заходить на нежелательные сайты. Оно следит за тем, какие страницы человек открывает в браузере, и если страница попадает под «плохую» категорию — перекидывает человека на Claude AI, где его мягко отговаривают и поддерживают.

## Платформа и механизм
- **Платформа:** Android (приоритет — телефон).
- **Механизм:** служба доступности (Accessibility Service) — читает **заголовок и адрес активной вкладки в любом браузере**, не привязываясь к одному браузеру.
- **Когда срабатывает:** по событиям смены экрана (открыл вкладку, переключил, страница догрузилась), с небольшой задержкой (~0.5 сек), чтобы заголовок успел прогрузиться, и с защитой от повторных запросов на одну и ту же страницу.

## Категории
- Человек **сам ведёт список категорий** «плохого» (например, порно) и дополняет его словами.
- Под **каждой категорией отдельно**:
  - свой переключатель **включить/выключить**;
  - своя **статистика** — сколько раз заблокировало (разбито по категориям).

## Логика блокировки
1. Claude анализирует **заголовок вкладки** и решает, подходит ли она под активную категорию.
2. Если подходит:
   - человека **перекидывает на сайт Claude AI**;
   - в **буфер обмена** заранее кладётся готовый **поддерживающий промпт** про эту страницу — чтобы Claude мягко **отговорил, поддержал и помог справиться с тягой**.

## Доступ к Claude
- **Основной путь (MVP):** токен аккаунта с подпиской.
  - ⚠️ Честная пометка: это неустойчиво и рискованно — против правил Anthropic, токены недолговечны, аккаунт могут забанить. Ок как хак на попробовать, шатко как основа продукта.
- **Запасной вариант:** обычный API-ключ. На бумаге; **код под него пока не пишем**.

## Экран настроек
- Список категорий (редактируется человеком).
- Под каждой категорией: переключатель вкл/выкл + статистика по этой категории.
- Поле для токена аккаунта.

## Открытые вопросы на будущее (вне MVP)
- **iPhone:** на iOS служба доступности так не работает — пока только Android.
- **Анализ содержимого страницы** (текст, картинки), а не только заголовок — если точности по заголовку не хватит.
- **Встроенный чат Claude** внутри приложения с автоматическим контекстом — вместо открытия сайта и буфера обмена.
- **Белый список** сайтов, которые не трогать.

## Решения, принятые при планировании (2026-10-03)

Эти решения заменяют соответствующие пункты выше.

- **Доступ к Claude:** вместо токена аккаунта приложение вызывает официальный Claude Code CLI (`claude -p`), установленный в Termux на этом же телефоне и залогиненный под Pro-подпиской. Вызов идёт через интент Termux `com.termux.RUN_COMMAND`. Поля для токена нет. Код под API-ключ не пишем.
- **Проверка в два слоя:** (1) на телефоне, мгновенно: домены категории (включая встроенный блоклист для «Порно») и слова категории в заголовке и адресе; (2) только если слой 1 ничего не нашёл и Claude включён: `claude -p --model haiku`. Если Claude недоступен или не ответил, страница пропускается.
- **Перекидывание:** открываем `https://claude.ai/new?q=<промпт>`. Тот же промпт дополнительно кладём в буфер обмена (на случай, если `?q=` не сработает).
- **Стек:** Kotlin, Jetpack Compose + Material 3, Room, DataStore, корутины/Flow, ручной DI. Модули `:core` (чистый Kotlin, вся логика) и `:app` (Android). minSdk 26.
- **Сборка APK:** GitHub Actions.
