# Спека: защита от отключения, категория YouTube и версия «для друга»

## Зачем

1. Друг тоже хочет поставить «Стража вкладок»: у него должны блокироваться порно и развлекательный YouTube.
2. Отключить защиту сейчас слишком легко — один переключатель (и у человека, и у друга).
3. Другу нужна простая установка и понятная инструкция без участия разработчика.

## Что сказал человек

- Отключение: **на выбор при установке** — пауза перед отключением или PIN у напарника.
- YouTube: **Shorts + развлекательные видео по словам в заголовке**; учебные проходят; точность не идеальна — это принято.
- Устройства друга: **iPhone + ПК с Windows (Chrome / Яндекс.Браузер)**; YouTube смотрит в приложении на телефоне.
- iPhone: **YouTube закрыт полностью** (через «Экранное время»); смотреть YouTube — только на ПК, где работает фильтр.
- ПК: **пока установка из папки** (не Web Store) — защита только на переключатели внутри расширения.
- Раздача: **публичная страница релизов GitHub** — репозиторий станет публичным.
- Инструкция: **одна веб-страница по ссылке**.
- Защита от отключения **нужна и на Android человека**, включая перехват системных настроек.
- Claude: друг пользуется **своим** аккаунтом claude.ai (подписку человека использовать нельзя); проверка через домашний сервер у друга не используется.

## Предположения

- Друг ставит добровольно, ради самоконтроля.
- Работа над сервером (`docs/superpowers/specs/2026-10-14-claude-server-design.md`) отложена; эта спека от неё не зависит.

## 1. Защита от отключения (Android и расширение)

### Режимы (выбираются в мастере, раздел 4)

- **Пауза**: «Хочу ослабить защиту» → отсчёт N минут (по умолчанию 20; при установке 5–60) → окно изменений 5 минут. Во время отсчёта — поддерживающий текст и кнопка «Поговорить с Claude» (claude.ai с промптом про желание отключить защиту). Отсчёт можно отменить.
- **Напарник**: PIN 4–8 цифр задаёт напарник; хранится `sha256(соль + PIN)` и соль. Верный PIN → окно 5 минут. 5 неверных подряд → ввод заблокирован на 30 минут.
- Время начала отсчёта, конца окна и блокировки PIN хранятся в настройках (переживают перезапуск фонового скрипта/процесса).

### Что требует открытого окна («ослабление»)

- выключить категорию, удалить категорию;
- сохранить категорию, если из неё убраны слова, домены или правила адреса (добавление — свободно);
- сменить режим защиты, длительность паузы, PIN;
- Android: открыть системную страницу службы доступности «Страж вкладок», экран удаления приложения, экран «О приложении» «Стража вкладок» (кнопки «Остановить»/«Удалить»). Служба распознаёт их по пакету настроек/установщика и по сочетанию названия приложения с элементами именно этих экранов (не любое упоминание «Страж вкладок»); при закрытом окне — «Назад» и уведомление-тост «Отключение защищено — откройте Страж вкладок».

Свободно всегда: добавлять категории, слова, домены; включать категории; смотреть статистику.

### Честные ограничения (пишутся в инструкции)

- ПК: расширение целиком отключается/удаляется на странице расширений в обход защиты (до перехода на Web Store + политику Windows).
- Android: безопасный режим или ADB обходят защиту.
- Забытый PIN: на ПК — переустановка расширения (категории сбросятся); на Android — удаление через безопасный режим.

## 2. Категория «YouTube: развлечения»

- Встроенная категория `youtube-fun`, `bundledList: "youtube-fun"`; у друга включается в мастере, у человека по умолчанию выключена.
- Новые поля категории:
  - `urlPrefixes: string[]` — блок, если адрес (без схемы и `www.`/`m.`) начинается с префикса; для категории: `youtube.com/shorts/`.
  - `onlyHosts: string[]` — слова категории (свои и встроенные) применяются только на этих хостах и их поддоменах; для категории: `youtube.com`, `youtu.be`. Пусто = везде (как сейчас).
- Встроенный словарь `blocklists/youtube-fun-keywords.txt` (общий файл Android и ПК): приколы, прикол, челлендж, реакция, мемы, стрим, нарезка, пранк, лучшие моменты, тикток, смешн, угар, ржака, топ 10, funny, prank, reaction, challenge, meme, memes, compilation, tiktok, shorts, try not to laugh, fails и т. п. — с тестами «блокируется» / «не блокируется» (лекция по физике, урок английского, как починить кран, documentary).
- Главная, поиск и подписки YouTube не блокируются (только Shorts и видео/страницы с подходящим заголовком).
- Свой промпт для Claude: про тягу к бесконечной ленте развлекательного контента.
- Где работает: расширение — да; Android — в браузерах (приложение YouTube на Android — вне рамок); iPhone — через «Экранное время» (раздел 5).

## 3. Подготовка репозитория и релизы

- Ключ подписи Android переносится в секрет GitHub `ANDROID_KEYSTORE_BASE64` (+ пароли в секретах), сборка декодирует его в CI; если секрета нет (форки) — сборка подписывается временным ключом.
- `app/debug.keystore` удаляется из всей истории (`git filter-repo`) с принудительной отправкой обеих веток. **Перед этим шагом — отдельное подтверждение человека.**
- Проверено: авторы коммитов — служебный адрес, токенов/паролей в репозитории нет.
- После этого человек включает «Public» в настройках GitHub.
- Релизы: пуш метки `v*` → workflow собирает и прикладывает к релизу `TabGuard-PC.zip` (TabGuard/ + install.bat + УСТАНОВКА.txt) и `TabGuard-Android.apk`; права `contents: write`. Ссылка для друга — `/releases/latest`.
- Версия расширения и приложения = метка; в настройках — «Версия X · Проверить обновления» (ссылка на `/releases/latest`).

## 4. Мастер первой настройки

Показывается, если режим защиты ещё не выбран (новая установка или первое обновление у человека; категории и статистика не трогаются).

1. Категории: «Порно» (вкл.), «YouTube: развлечения» (по умолчанию выкл., у друга включит сам).
2. Режим защиты: «Пауза» + длительность или «Напарник» + PIN дважды.
3. ПК: напоминание включить «Разрешить в режиме инкогнито». Android: проверка, что служба доступности включена.

Расширение: мастер — страница расширения, открывается при установке (`runtime.onInstalled`) и из настроек, пока режим не выбран. Android: экран перед основным.

## 5. Инструкция для друга — веб-страница

- `site/index.html` (+ картинки), публикация через GitHub Pages (workflow), адрес `https://area-ufa1.github.io/AiBlockSite/`.
- Разделы: ПК (скачать → install.bat → режим разработчика → загрузить распакованное → мастер → инкогнито; скриншоты расширения и мастера — снимаются в Chromium); iPhone «Экранное время» (запрет YouTube, «Ограничить сайты для взрослых», код-пароль — сам или напарник; текстовые пути меню, без скриншотов iOS); claude.ai — регистрация своего аккаунта; «если нужно отключить»; честные ограничения.
- Работает на телефоне и ПК (адаптивная вёрстка), русский язык.

## Проверка

- Логика блокировки (urlPrefixes, onlyHosts, словарь YouTube) — тесты в `pc/` и `:core`.
- Защита (пауза, окно, PIN, блокировка попыток, что считается ослаблением) — чистые модули с тестами в `pc/` и `:core`.
- Расширение — сквозные Playwright-сценарии: Shorts → Claude; учебное видео проходит; выключить категорию без окна нельзя; после паузы (сокращённой в тесте) можно; PIN.
- Android — Robolectric: ViewModel блокирует ослабление без окна; распознавание защищённых экранов настроек на тестовых деревьях узлов.
- Релиз — workflow на тестовой метке в форке/ветке; страница инструкции — снимок в Chromium.
- Вживую: человек — Android (перехват настроек), друг — ПК и iPhone по инструкции.

## Вне рамок

- Chrome Web Store и политики Windows (принудительная установка).
- Приложение YouTube на Android, iPhone-приложение.
- Проверка через домашний сервер у друга.
