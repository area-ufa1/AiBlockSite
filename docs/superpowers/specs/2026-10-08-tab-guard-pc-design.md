# Спека: «Страж вкладок» для ПК (расширение для браузера)

## Зачем

Тот же самоконтроль, что и в Android-приложении, но на компьютере: не давать себе заходить на нежелательные сайты. Если страница попадает под включённую категорию, вкладка уходит в Claude с поддерживающим промптом.

## Что сказал человек

- Система: **Windows 11**.
- Браузеры: **Chrome** и иногда **Яндекс.Браузер**.
- Уровень защиты: **лёгкий** (программу/расширение можно убрать, если очень захотеть; усиливать будем потом).
- Подход: **расширение для браузера** (вариант A).
- При блокировке: **сразу Claude**, как на телефоне (своя страница «Стоп» — возможно позже).
- Установка: **из папки, упрощённая скриптом `install.bat`** (Chrome Web Store — возможно позже).
- Claude-классификация заголовков (как `claude -p` на телефоне) — **не делаем**.

## Предположения

- Только для одного человека, на одном компьютере.
- С телефоном ничего не синхронизируется.
- Интерфейс и промпты на русском.

## Устройство

Расширение Manifest V3 в папке `extension/` этого репозитория. Обычный JavaScript (ES-модули) **без сборки**: папка `extension/` и есть то, что загружается в браузер.

Логика переносится с Android (`core/`) один в один:

- нормализация: нижний регистр, `ё→е`, разбиение на токены по не-буквам/цифрам;
- слово совпадает только **с начала токена** («sex» не ловит «Sussex»); фраза из нескольких слов — подряд идущие токены; пустые слова игнорируются;
- домен совпадает сам или как родитель поддомена (`rt.pornhub.com` → `pornhub.com`), поиск по суффиксам хоста в `Set`;
- исключения: `claude.ai`, `anthropic.com` и страницы самого расширения никогда не блокируются;
- текст поддерживающего промпта и ссылка `https://claude.ai/new?q=<URL-encoded промпт>` — те же, что в `core/.../support/SupportPrompt.kt`.

### Когда срабатывает

1. **До загрузки страницы** — `chrome.webNavigation.onBeforeNavigate` (только основной фрейм): проверяются домен и слова в адресе (включая поисковый запрос). Совпало → вкладка сразу переводится на Claude, сайт не начинает грузиться.
2. **По заголовку** — `chrome.tabs.onUpdated`, когда у вкладки появился или поменялся заголовок: проверяются слова категорий. Совпало → вкладка переводится на Claude.

Одна и та же вкладка с одним и тем же адресом не блокируется повторно чаще раза в 2 секунды (защита от двойного срабатывания на шаги 1 и 2).

### При блокировке

1. Вкладка открывает `claude.ai/new?q=<промпт>`.
2. Промпт копируется в буфер обмена (через offscreen-документ, причина `CLIPBOARD`).
3. Счётчик категории +1.

### Хранение

`chrome.storage.local`:

- `categories`: список `{ id, name, enabled, keywords: string[], domains: string[], bundledList: string | null }`;
- `stats`: `{ [categoryId]: number }`.

При первой установке создаётся категория «Порно», включена, `bundledList: "adult"`, слова: `порно, porn, xxx, секс, sex, хентай, hentai, nsfw, onlyfans, эротика`.

Встроенный список — тот же файл, что в Android-приложении (`app/src/main/assets/blocklists/adult.txt`, ~64 тыс. доменов); копируется в `extension/blocklists/adult.txt` при сборке архива. Загружается в `Set` в фоновом скрипте при старте (фоновый скрипт MV3 может засыпать — список перечитывается при пробуждении).

Слова и домены при сохранении нормализуются так же, как на телефоне: разделители — перевод строки и запятая, пустые отбрасываются, у доменов срезается схема/`www.`/путь.

### Инкогнито

`"incognito": "spanning"`. Работает, если в карточке расширения включено «Разрешить в режиме инкогнито»; страница настроек показывает предупреждение, если это не включено (`chrome.extension.isAllowedIncognitoAccess`).

### Разрешения

`storage`, `tabs`, `webNavigation`, `offscreen`, `clipboardWrite`. Без доступа к содержимому страниц.

## Страница настроек

Открывается по клику на значок расширения (тот же щит, что у Android-приложения). Повторяет экран телефона:

- статус: «Защита работает» + предупреждение про инкогнито, если не разрешено;
- список категорий: название, переключатель вкл/выкл, «Заблокировано: N»;
- клик по категории → редактирование: название (обязательно), слова и домены (по одному в строке), «Удалить» с подтверждением; для категории со встроенным списком — подпись «+ встроенный список (N доменов)»;
- «+ Добавить категорию».

## Установка и обновление

Сборка в GitHub Actions (тот же workflow, отдельная задача) выкладывает артефакт `tab-guard-extension` с содержимым:

```
TabGuard/          — само расширение
install.bat        — установка/обновление
УСТАНОВКА.txt      — короткая инструкция
```

`install.bat`:

1. копирует `TabGuard/` в `%LOCALAPPDATA%\TabGuard` (без прав администратора, перезаписывая старую версию);
2. кладёт путь к этой папке в буфер обмена;
3. открывает `chrome://extensions` в Chrome (если Chrome установлен) и подсказывает, что делать дальше.

Первая установка, руками: «Режим разработчика» → «Загрузить распакованное» → вставить путь из буфера → в карточке расширения включить «Разрешить в режиме инкогнито». В Яндекс.Браузере то же самое на странице `browser://extensions`.

Обновление: запустить `install.bat` новой версии → на странице расширений нажать «Обновить» у «Стража вкладок». Категории и статистика сохраняются.

Известное ограничение: Chrome может показывать уведомление про расширения в режиме разработчика — его можно закрыть, расширение продолжает работать.

## Проверка

- Логика (нормализация, сопоставление, исключения, промпт, разбор ввода) — автотесты на `node --test`, запускаются локально и в CI.
- Работа в живом браузере — чек-лист `docs/manual-test-pc.md`, проходит человек: Chrome, Яндекс.Браузер, инкогнито, поиск со словом, сайт из списка, обычные сайты, выключенная категория, нет петли на claude.ai.

## Вне рамок (возможно позже)

- Своя страница «Стоп» вместо мгновенного перехода в Claude.
- Средняя/жёсткая защита: программа в трее/служба Windows, пауза перед отключением, запрет других браузеров.
- Публикация в Chrome Web Store «по ссылке» с автообновлением.
- Классификация заголовков через Claude.
- Синхронизация категорий с телефоном.
