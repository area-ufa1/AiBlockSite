# Приёмочная проверка на телефоне

## Установка

1. GitHub → Actions → последний зелёный прогон «Android» → артефакт `tab-guard-debug-apk` → скачать, распаковать, установить APK.
2. Открыть «Страж вкладок» → «Включить» → в настройках специальных возможностей включить службу «Страж вкладок».
3. (Для Claude) настроить Termux по `docs/termux-setup.md`, включить «Проверять через Claude (Termux)», нажать «Проверить связь».

## Чек-лист

Для каждого браузера поставьте ✅ / ❌ и, если ❌, коротко — что произошло.

## Заметки

- Если в каком-то браузере ничего не происходит — скорее всего, у него своя адресная строка с неизвестным id. Пришлите название браузера, добавлю id.
