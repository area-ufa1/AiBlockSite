# Что ещё стоит улучшить

Список идей после версии 1.2.0.

## Сначала проверить вживую

- [ ] Перехват системных настроек на Android: экраны «Остановить», «Удалить», страница службы доступности, окно «Остановить принудительно?».
- [ ] Блокировка YouTube по категории видео и скрытие рекомендаций на настоящем youtube.com (проверено только на тестовых страницах).

## Защита

- [ ] **Расширение на ПК нельзя удалить в обход защиты.** Опубликовать в Chrome Web Store (разовый взнос 5 $) и закрепить политикой Windows (`ExtensionInstallForcelist`), чтобы пропала кнопка «Удалить». Заодно — автоматические обновления без архива и install.bat.
- [ ] **Другие браузеры на ПК.** Поставить расширение в Edge (работает так же); в инструкции — совет убрать лишние браузеры или закрыть их родительским контролем Windows.

## Приложение YouTube на Android

Сейчас там закрываются только Shorts (по элементу `reel_progress_bar`). Вернуться, когда найдётся человек с Android и приложением YouTube, который проверит:

- [ ] **Названия видео через «Сейчас играет».** Разрешение «Доступ к уведомлениям» → MediaSession приложения YouTube → название и канал → словарь YouTube. Не проверено, отдаёт ли YouTube название без Premium (проверка: опустить шторку во время видео — есть ли карточка плеера с названием). Страницу этого разрешения сделать защищённой.
- [ ] **Запись экрана для отладки.** Долгое нажатие на «Версия …» → следующий экран YouTube (тексты и названия элементов, без картинок) + данные «Сейчас играет» сохраняются в файл и открывается «Поделиться».

## Удобство

- [ ] **Словари без нового релиза.** Раз в сутки подтягивать свежие словари с GitHub (расширение и приложение), чтобы новое слово не требовало переустановки.
- [ ] **Лимит времени на YouTube** — например, 30 минут в день, потом сайт закрыт до завтра.
- [ ] **Настройка «музыку не трогать»** — не закрывать видео с категорией «Музыка».
- [ ] **Статистика для мотивации** — дни подряд без срывов, итоги недели.

## Мелочи из ревью кода

- [ ] Android: если сохранение категории запрещено защитой, правки в редакторе теряются (на ПК редактор остаётся открытым).
- [ ] Android: мастер не проверяет, что служба доступности включена.
- [ ] Нет уведомления, когда пауза кончилась и изменения открыты — легко пропустить 5-минутное окно.
- [ ] Имя и пароль ключа подписи (`TABGUARD_KEY_ALIAS`, `TABGUARD_KEY_PASSWORD`) не берутся из секретов; сейчас подходят значения по умолчанию.
- [ ] Метки вида `v1.0.0-rc1` дают недопустимую версию в manifest.json — выпускать только `vX.Y.Z` или отрезать суффикс.
- [ ] Android: служба обходит всё дерево экрана при каждом событии из настроек — можно сначала искать название приложения в заголовке окна.
- [ ] Настройки расширения: обработчик изменений хранилища дважды обновляет статус защиты.
